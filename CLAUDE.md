# claude-tag-portfolio — rules for anyone (human or agent) editing this repo

Start with `docs/README.md` (the map) and the root `README.md` (the manual).

- **Overrides only.** Project metadata is changed in `data/overrides.json` (bare repo name, or `owner/repo` for repos
  outside the org). Extra repos / users outside the org go in `data/sources.json`. Never edit `data/projects.json`
  by hand: it is generated by `.github/workflows/update.yml`; locally only `node scripts/build-data.mjs --recompute` may touch it.
- **Build green before every push:** `node scripts/build-data.mjs --recompute` must exit 0 with no warnings, and the
  page must load `data/projects.json` without console errors (`npm run serve`).
- **Docs in the same turn:** every prompt (verbatim) in `docs/prompts/NNNN-slug.md`, its changelog in
  `docs/changelog/NNNN-slug.md` (K-01 header lines + Verification), kanban move, decisions, page doc (`docs/pages/HOME.md`)
  and `docs/reference/surfaces.md`. Numbered files are append-only; never renumber. See `docs/rules/documentation.md`.
- **Git only:** Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`), one logical change per commit, commit and
  push to `main`; no pull requests. Model names go in the docs (policy asks for them there), never in code or commit subjects.
- **Screenshots** in `screenshots/` are captures of the catalogued sites made by the workflow; do not hand-add or rename them
  (the build carries them over on renames; external repos use `owner--repo.png`).
