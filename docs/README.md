# claude-tag-portfolio documentation

Start here. The portfolio is a static catalogue of every repository in the `imagine-os` GitHub
organization plus the repos listed in `data/sources.json`, generated by `scripts/build-data.mjs` and
served by GitHub Pages at https://imagine-os.github.io/claude-tag-portfolio/. The repo manual
(what the site shows, how it updates, how to run it) is the root `README.md`; this folder holds the
working memory: rules, prompt log, changelog, decisions, kanban, page docs and surfaces.

## Map
| Path | What |
| --- | --- |
| `rules/documentation.md` | The documentation rules: prompt log, changelog, kanban, decisions, page docs. |
| `prompts/NNNN-slug.md` | Every prompt verbatim + the response summary (`## Response` heading). |
| `changelog/NNNN-slug.md` | K-01 entries: version, date, prompt, intent, decision, rejected, files, then Verification. |
| `decisions.md` | Numbered decisions (`D-NNNN`) with date, status and the alternative rejected. Append-only. |
| `kanban.md` | Live board: General lane (Backlog / Doing / Done / Blocked), updated every turn. |
| `reference/surfaces.md` | MCP / WebMCP, CLI and API abilities of this repo, recorded every pass. |
| `pages/HOME.md` | Page doc for `index.html` (the only page): views, hash state, keyboard, theme, detail panel, actions. |
| `../CLAUDE.md` | The short rule sheet for anyone (human or agent) editing this repo. |
| `../data/overrides.json` | The only hand-maintained data file (per-repo overrides). |
| `../data/sources.json` | Committed extra repos / users outside the org (D-0001). |
| `../data/projects.json` | GENERATED by the workflow; never hand-edited (D-0001, `CLAUDE.md`). |

## Conventions
- Markdown, English. Dates are ISO (`2026-09-19`), times UTC.
- Numbered files (`0001-…`) are append-only; never renumber. Prompt and changelog share a number.
- Every prompt names the model that did the work; the policy asks for it, so it lives in the docs, never in code.
- Project screenshots live in `screenshots/` at the repo root (captures of the catalogued sites, 1440x900 + thumbs);
  do not mix them with docs captures, which go under `docs/screenshots/` if they are ever needed.
- Same-turn rule: prompt, changelog, kanban move, decisions and page docs land in the same commit series as the work.
