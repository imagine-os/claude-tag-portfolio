## CLI
All Node 20+, ESM, zero runtime deps. Run from the repo root.

| Command | What |
| --- | --- |
| `npm run data` → `node scripts/build-data.mjs` | Queries the GitHub REST API for every repo in `$PORTFOLIO_ORG` plus `$PORTFOLIO_USERS`, `$PORTFOLIO_EXTRA_REPOS` and `data/sources.json`; enriches; merges `data/overrides.json`; writes `data/projects.json`. |
| `node scripts/build-data.mjs --recompute` | Offline: re-derives status / category / stack / placeholder / links and re-applies overrides to the existing `data/projects.json`. Must exit 0 before every push. |
| `node scripts/build-data.mjs --self owner/repo` | Names the portfolio repo to exclude (default `$GITHUB_REPOSITORY` or `imagine-os/claude-tag-portfolio`). |
| `node scripts/build-data.mjs --help` | Usage. |
| `npm run shots` → `node scripts/screenshot.mjs` | Playwright captures of every live URL (1440x900 + 640x400 thumbs). Env: `PORTFOLIO_SHOT_ONLY`, `PORTFOLIO_SHOT_CONCURRENCY`, `PORTFOLIO_CHROMIUM_PATH`. |
| `npm run check` → `node scripts/check-live.mjs <url…>` | HTTP live check of one or more URLs (exit 0 when all are 2xx). |
| `npm run serve` | `python3 -m http.server 8765 --bind 127.0.0.1`. |
| `node scripts/merge-gathered.mjs --from <gathered.json>` | First-run path: turns a locally gathered JSON into `data/projects.json` without the API. |

Env for `build-data`: `PORTFOLIO_TOKEN` \| `GITHUB_TOKEN`, `PORTFOLIO_ORG`, `PORTFOLIO_USERS`, `PORTFOLIO_EXTRA_REPOS`,
`PORTFOLIO_SKIP_LIVE=1`, `PORTFOLIO_SKIP_TODOS=1`.

## API
None served. The read surface is the static JSON the site itself loads:

- `https://imagine-os.github.io/claude-tag-portfolio/data/projects.json` — regenerated by the Action every 6 h and on push.
  Top level: `generated_at, org, api_reachable, sources { org, users, extra_repos, file { path, extra_repos, users }, excluded }, errors[], projects[]`.
  Entry schema: see the "Entry keys" list in the root `README.md` and the derivation rules in `scripts/build-data.mjs`
  (`STATUSES`, `CATEGORIES`, `deriveStatus`, `deriveCategory`).
- `data/overrides.json` and `data/sources.json` are the write surface, through git.
